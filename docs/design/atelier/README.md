# Atelier hi-fi prototype (reference)

- **`Atelier Hi-fi Prototype (1).html`** — primary reference. Self-contained export (opens offline in a browser),
  45 screens incl. the full admin console, with its photos embedded. The embedded Home carousel photos
  (mehendi hands, makeup, 1200×800 JPEG) are the source for `mobile/assets/hero/` when Home is built.
- `Atelier Hi-fi Prototype.dc.html` — raw source from Claude Design project `78770b42-a64a-4794-a923-399403a73753`;
  needs that project's `support.js`/`image-slot.js` to render. Handy for reading exact markup and colours.
- Welcome / Choose role photos: `mobile/assets/hero/welcome.webp`, `role-customer.webp`, `role-artist.webp` are the Claude Design project's `assets/hero/welcome2.jpg`, `role-client.jpg`, `role-creator.jpg` (v4 screens), re-encoded as webp.

To check a screen: open the export, pick it in the left rail; compare against the app rendered at 393×852.
